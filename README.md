# 🤖 AI-Assistant

An AI-powered Personal Assistant built with **Python**, **Google Gemini AI**, and **Gradio**. It integrates with Gmail, Slack, and WhatsApp (Twilio) to provide a unified conversational assistant.

---

## ✨ Features

- 🤖 Gemini AI Chat
- 📧 Gmail Integration
- 💬 Slack Integration
- 📱 WhatsApp Integration (Twilio)
- 🌐 Gradio Web Interface
- 🔒 Environment Variable Support (.env)
- 🚀 Deployable on Render
- 💻 One-Click Windows Launcher

---

## 🚀 Installation

### Clone the Repository

```bash
git clone https://github.com/rutika-wq/AI-Assistant.git
```

```bash
cd AI-Assistant
```

### Install

Double-click

```
install.bat
```

or run

```bash
install.bat
```

### Configure Environment

Copy

```
.env.example
```

to

```
.env
```

Fill in your API keys.

### Run

Double-click

```
run.bat
```

or execute

```bash
python main.py
```
